최종 수정일: 2026년 7월 30일

핵심 요약
이 앱은 인터넷 연결 기능이 없습니다. 수집한 모든 정보는 사용자의 휴대전화 안에만 저장되며, 어떤 서버로도 전송되지 않습니다. 개발자를 포함해 누구도 사용자의 데이터를 열람할 수 없습니다.

1. 수집하는 정보

항목내용사용 목적
문자메시지(SMS/MMS) 카드사·은행이 보낸 결제 알림 문자의 본문과 수신 시각 결제 금액·사용처·카드를 읽어 가계부에 기록
알림 내용 사용자가 허용한 경우, 금융 앱 알림의 텍스트 문자로 오지 않는 결제(앱 푸시)를 기록
사용자 입력 직접 입력한 거래·태그·자산·예산 가계부 기능 제공

2. 정보의 저장 위치

모든 정보는 휴대전화 내부 저장소의 앱 전용 데이터베이스에만 저장됩니다. 외부 서버, 클라우드, 개발자에게 전송되는 정보는 없습니다.

3. 제3자 제공 및 광고

제3자에게 제공하거나 판매하지 않습니다. 광고 모듈, 분석 도구, 추적 도구를 일절 포함하지 않습니다.

4. 인터넷 접근 권한 없음

이 앱은 안드로이드의 인터넷 권한(android.permission.INTERNET)을 요청하지 않습니다. 기술적으로 데이터를 외부로 보낼 수 없습니다. 휴대전화 설정 → 앱 → 우리집 가계부 → 권한에서 직접 확인하실 수 있습니다.

5. 요청하는 권한과 이유

권한이유없으면
SMS 수신 (RECEIVE_SMS)결제 문자가 도착한 즉시 인식실시간 기록 불가
SMS 읽기 (READ_SMS)‘지난 문자 가져오기’로 과거 결제 내역 한 번에 등록과거 내역 가져오기 불가
알림 표시 (POST_NOTIFICATIONS)등록 결과·예산 초과를 알림알림 없음
알림 접근 (선택)카드사 앱 푸시 등 문자가 아닌 결제 알림 인식앱 푸시 결제 누락

알림 접근 권한은 선택 사항이며, 허용하지 않아도 앱의 나머지 기능은 정상 동작합니다.

6. 보관 기간과 삭제

데이터는 사용자가 삭제하기 전까지 휴대전화에 남습니다. 앱 안의 더보기 → 처음부터 다시 시작으로 지우거나, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다. 개발자는 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

7. 데이터 내보내기

사용자가 원할 때 CSV 또는 JSON 파일로 내보낼 수 있습니다. 내보낸 파일의 저장 위치와 공유 여부는 전적으로 사용자가 정합니다. 앱이 자동으로 전송하지 않습니다.

8. 아동 개인정보

이 앱은 만 14세 미만을 대상으로 하지 않으며, 연령 정보를 수집하지 않습니다.

Our Home Budget (우리집 가계부) — Privacy Policy

Last updated: July 30, 2026

Summary. This app has no internet capability. Everything it reads stays on the user's phone. No data is transmitted to any server. Not even the developer can access it.

1. Information the app reads

  • SMS/MMS messages — the text and timestamp of payment notification messages sent by card issuers and banks, used to extract the amount, merchant and card for the user's expense log.
  • Notification text — only if the user enables notification access, so that card issuer app pushes (which never arrive as SMS) can also be recorded.
  • User input — transactions, tags, assets and budgets entered by the user.

2. Storage

All data is stored solely in the app's private database on the device. Nothing is uploaded.

3. Sharing, ads and analytics

No data is shared or sold. The app contains no advertising, analytics or tracking SDKs.

4. No internet permission

The app does not request android.permission.INTERNET. It is technically incapable of sending data off the device. This can be verified in Android system settings.

5. Permissions and purpose

  • RECEIVE_SMS — recognise a payment message the moment it arrives.
  • READ_SMS — the "import past messages" feature, which registers previous payments in one go.
  • POST_NOTIFICATIONS — inform the user of a recorded transaction or a budget overrun.
  • Notification listener access (optional) — capture payments delivered as app pushes rather than SMS.

6. Retention and deletion

Data remains on the device until the user deletes it, either via More → Start over inside the app or by uninstalling the app. The developer holds no copy, so no deletion request process is needed.

7. Export

The user may export data to CSV or JSON at any time. Where that file goes is entirely the user's choice; the app never transmits it.

8. Children

The app is not directed at children and collects no age information.
